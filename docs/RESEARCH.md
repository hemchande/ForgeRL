# Research benchmark

Six authored synthetic coding families, four independent cases each, disjoint discovery and held-out families. A scripted user requirement update arrives at step two; premature finish is rejected until delivery. This is an interaction proxy, not real sentiment. Baseline, context reinforcement, caching, action guidance, and context+cache ablations are frozen before held-out evaluation. An optional generated candidate is learned only from the first model's discovery evidence and transferred unchanged to all models.

Run with an OpenAI-compatible endpoint serving the named models:
    python -m forgerl.research --models MODEL_A MODEL_B --meta-model MODEL_A --judge JUDGE --samples 2

The optional semantic judge is diagnostic and never controls correctness. Malformed responses are recorded and corrected via observations; infrastructure failures and step limits are retained rather than dropped. The SQLite store preserves partial results and reports per-model deltas. No automatic promotion. The manual GitHub workflow runs two CPU models without paid API credentials. CPU time may exceed timeout. The benchmark uses sequential variant batches with concurrent episodes; it does not claim independent parallel development agents. Tests are synthetic single-file tasks, not real repository issues. Repeated samples use temperature zero, so they are not independent stochastic draws. No confidence intervals for this tiny suite, no actual user satisfaction, no robust hostile-code verifier, no proven improvements. Model digests are recorded by workflow. Token usage depends on provider reporting. Latency includes sandbox provisioning and verification. Semantic judge input is truncated and may miss evidence. Cross-model results must be measured, not assumed.
